# Ticket checkout — пошаговый UI↔API
# Контекст: SERVICE.md §7, legal-ticketing-review.md, tbank-payments.md
# Чеклист: production-readiness-checklist.md
# Важно: features.ticketSalesEnabled по умолчанию false.
# Целевой провайдер: Т-Банк (marketplace). yookassaStub — локалка без банка.
# Кошелёк платформы к билетному флоу не относится (отдельный deposit).

UI → API, шаг за шагом (Cost > 0, provider=tbank)
Карточка события
  CTA: «Купить билет»  (не Participate)
       │
       ▼
[опц.] Экран подтверждения: цена = Cost, qty (пока обычно 1)
       │
       ▼
POST /eList/api/orders
  { eventId, quantity: 1, idempotencyKey? }

Что делает API на create
Проверки флага / TicketsEnabled / доступа / мест / продавца (ShopCode).
Считает: amountTotal = Cost × qty, комиссия из payments.commissionPercent, остальное продавцу.
Пишет заказ Pending.
Init Т-Банк (PayType=O, Shops+Fee при ShopCode) → providerPaymentId + confirmationUrl (PaymentURL).
Ответ:
paidImmediately: false
order (Pending)
confirmationUrl, providerPaymentId
UI сохраняет orderId (sessionStorage) / открывает confirmationUrl
       │
       ▼
Пользователь платит на стороне банка → SuccessURL/FailURL
  …/payments/return?orderId={guid}&…
       │
       ▼
UI /payments/return
  stub (?stub=1) → POST …/orders/payments/complete
  T-Bank → poll GET /eList/api/orders/{id}
    (бэкенд при Pending дергает GetState, если webhook ещё не пришёл)

Что делает API на webhook CONFIRMED / GetState Succeeded
Fulfill: заказ → Paid, quantity билетов, Participate, invite cleanup, notify.
UI: экран успеха («Вы идёте» / билет / QR).

Если Cost = 0 при TicketsEnabled
Тот же POST /orders, без оплаты: paidImmediately: true. complete/webhook не нужны.

Чего UI не должен делать
GET …/participations/participate/{id} - При TicketsEnabled → «нужно купить билет»
Accept приглашения как вход - То же
POST payments/complete после реального PaymentURL T-Bank - только stub (?stub=1)

Краткая схема денег
Cost (event_parameters)  →  цена одной позиции
quantity                 →  число билетов
комиссия %               →  amountCommission / Fee в Init; amountSeller → ShopCode
кошелёк/тариф платформы  →  другой контур (OrderId wallet:{depositId})
Ценовые категории билетов ещё не в модели.
