# Agreements — исходники юридических документов

> Добавлены в git: 14 сентября 2026.  
> **Это черновики/источники для редакции.** Рабочие версии, которые видит клиент, хранятся в БД (таблица документов) и отдаются API `/api/agreements/...`.

| Файл | `DocumentType` | Галочка принятия |
|------|----------------|------------------|
| `Политика обработки персональных данных.txt` | `Policy` (0) | **Не требуется** (информационный документ) |
| `Согласие на обработку персональных данных.txt` | `Consent` (1) | Обязательна (регистрация / re-consent) |
| `Пользовательское соглашение.txt` | `Agreement` (2) | Обязательна (регистрация / re-consent) |
| `Соглашение для организаций.txt` | `OrganizationAgreement` (3) | Org-флоу |
| `Агентский договор на продажу билетов.txt` | `TicketingAgreement` (4) | Подключение продажи билетов |

Перед заливкой новой редакции в prod БД:

1. Заполнить плейсхолдеры реквизитов Оператора.
2. Для агентского договора — закрыть альтернативы в §2.1 и §6.2 (см. [docs/legal-ticketing-review.md](../docs/legal-ticketing-review.md)).
3. Синхронизировать версию/дату с записью в БД.

Продуктовая модель и Policy/wallet правила: [docs/SERVICE.md](../docs/SERVICE.md).
